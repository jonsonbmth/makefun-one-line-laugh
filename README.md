Entry for the make.fun bounty **The One-Line Laugh**
([u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f)):
one funny line, a single sentence of at most 200 characters.

## The line

> My smartwatch praised me for burning 500 calories, then tattled that the pizza I just ordered has 900.

## Run

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints it to stdout.
It takes no arguments, uses only the Python standard library, and is
deterministic: every run produces the same line.

## Layout

- `main.py` — the entrypoint; writes `/output/entry.txt`
- `LICENSE` — MIT
- `.makefun/owner.json` — claim wallet for the entry
